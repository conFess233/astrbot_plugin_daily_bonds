整合每日老婆/老公功能，并支持娶群友。内置《鸣潮》角色与角色池，也支持管理员添加角色、图片和角色池。

<a id="quick-start"></a>

## 快速开始

运行要求：AstrBot >= `4.28.2` ，仅支持aiocqhttp平台。

1. 克隆仓库或从插件市场安装。
2. 在 **AstrBot 所用的 Python 环境**中进入该插件目录，安装依赖并重启 AstrBot：

    ```bash
    python -m pip install -r requirements.txt
    ```

3. 在 AstrBot 插件配置中保持宿主开关 `enabled=true`。进入本插件管理页后确认领域开关 `enabled=true`、群允许参与，并等待内置角色图片下载完成。首次运行会建立数据库、内置角色和角色池；图片下载失败时可能只返回文字。
4. 在已接入的 QQ 群发送 `娶群友` 验证消息链路；发送 `今日老婆` 或 `今日老公` 验证角色池。成功时返回对象名称，能取得图片时一并发送图片。群成员名单需要 OneBot 端支持获取。

内置目录中的部分角色因原始素材不适合独立立绘而默认禁用。管理员可在管理页查看和补充图片。

## 群内指令

下表是默认关键词，可在管理页逐项修改。`<…>` 为必填，`[…]` 为可选，输入时不带括号。`@用户` 必须是 QQ 的真实 At 消息段，直接打出 `@名字` 文本不算。

| 指令                                                                  | 作用                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `今日老婆` / `今日老公` / `娶群友`                                    | 从相应角色池或当前合格群成员中抽取；名额已满时展示已有关系。          |
| `抢老婆 @持有者 [名称或#ID]` / `抢老公 @持有者 [名称或#ID]`           | 抢指定持有者的关系；省略对象时随机选择。也可将 `@持有者` 放在指令前。 |
| `抢群友 @持有者 [QQ号]`                                               | 抢该持有者的群友关系；可省略配偶 QQ 号。                              |
| `送老婆 @接收者 [名称或#ID]` / `送老公 @接收者 [名称或#ID]`           | 将自己持有的关系赠送给群成员。                                        |
| `送群友 @接收者 [QQ号]`                                               | 赠送自己的群友关系。                                                  |
| `离婚 [名称、#ID、QQ号或@成员]`                                          | 解除自己的老婆、老公或群友关系；只有一段关系时可省略目标。              |
| `离婚老婆 [名称或#ID]` / `离婚老公 [名称或#ID]`                        | 只查对应玩法；多段关系时需指定目标。                                  |
| `离婚群友 [@成员、QQ号或完整名称]` / `踹群友 [@成员、QQ号或完整名称]` | 解除自己的群友关系，不会将对方踢出群；支持结婚时及当前成员名称。      |
| `老婆列表 [页码]` / `群友列表 [页码]`                                 | 查看本群当前关系。                                                    |
| `亲密度排行 [页码]` / `活跃度排行 [页码]`                             | 查看本群排行；排行方式和统计窗口由配置决定。                          |
| `接受赠送 [邀请编号]` / `拒绝赠送 [邀请编号]` / `取消赠送 [邀请编号]` | 处理需确认的赠送；同时有多条待处理邀请时必须填写编号。                |

角色 `#ID` 是角色的固定 ID，不进行模糊搜索。离婚指令只匹配自己在本群当前周期的关系；跨玩法或同名匹配时列出候选，需改用明确玩法及目标。一次普通抽取的每日总额度默认等于该玩法的持有容量；成功解除关系会获得一次补抽资格。抢夺有独立的概率、次数和冷却；有效抢夺尝试即使失败也会计入次数。赠送默认直接完成，可改成接收者确认模式。周期按配置的时区和重置时间计算。

今日老婆或今日老公达到持有上限后再次抽取时，只发送文字，不发送关系列表图。上限为 1 时分别提示“你今日已有老婆啦，请明日再来。”或“你今日已有老公啦，请明日再来。”；这两句可在消息配置中修改。上限大于 1 时仍以文字列出已有关系。

管理页“数据查询”中可按群和玩法预览并执行“重置关系”或“重置每日数据”。两者仅作用于当前周期：前者结束活跃关系，但不恢复每日额度或发放补抽；后者清零每日抽取、偷取和离婚计数，但不结束关系。历史、亲密度、活跃度、补抽资格及待处理赠送均保留。关系重置后，绑定原关系的待处理赠送会在接收时提示失效。

默认支持裸关键词、宿主当前命令前缀和开头 At 机器人。未识别的聊天不会收到插件回复。通用指令冷却默认 3 秒；格式错误、保护拒绝和额度不足不会开启新冷却，接受、拒绝和取消赠送不受通用冷却约束。

## 配置

AstrBot 原生插件配置页可编辑全部全局业务配置。顶层 `enabled` 是**宿主启动开关**：关闭后插件不打开数据库；`settings.enabled` 是**领域开关**：可暂停全局或单个群的玩法。两者都需启用。原生配置页与管理页的全局配置会同步；群级覆盖仍在管理页编辑。已有管理页配置在升级时保留。

管理页按主题提供配置子标签，切换标签时保留未保存草稿。选择「全局」或一个群后修改字段，依次使用**校验草稿**和**保存配置**；**放弃草稿**撤销未保存编辑。群配置逐字段标明「继承全局」或「本群覆盖」，关闭覆盖即恢复继承。全局资源、历史保留和群访问规则只能全局配置。保存会校验完整生效配置和版本；冲突时保留草稿。新配置在后续群事件中生效，当前周期的重置安排按周期规则延续。

「群内操作结果」「群内错误提示」「赠送与重启通知」分区可逐条修改机器人文案。带变量的文案使用 `{name}`、`{invite_id}` 等占位符；每项控件会列出允许的变量，预检会拒绝未知变量、无效大括号，以及会使抽取对象或邀请编号消失的缺失变量。输入 `{{`、`}}` 可显示字面大括号。消息文案也可按群覆盖；已经排入发送队列的通知保留入队时的文本。

常用字段如下，完整字段、默认值与结构见 [resources/default-config.json](./resources/default-config.json)。管理页可编辑其中所有可写项，无需手写 JSON。

| 配置键                                                                  | 默认值                       | 作用                                                         |
| ----------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| `enabled`                                                               | `true`                       | 领域总开关；群级可单独暂停。                                 |
| `access.groups.mode` / `access.users.mode`                              | `unrestricted`               | `unrestricted`、`blacklist`、`whitelist`；空白名单拒绝全部。 |
| `access.extra_bot_ids`                                                  | `[]`                         | 补充无法自动识别的机器人 QQ 号，避免进入候选或统计。         |
| `reset.timezone` / `reset.time`                                         | `Asia/Shanghai` / `00:00`    | 每日周期所用 IANA 时区和 `HH:mm` 时间。                      |
| `commands.cooldown_seconds`                                             | `3`                          | 通用指令冷却，`0` 关闭，最大 `86400` 秒。                    |
| `modes.<mode>.capacity`                                                 | `1`                          | 各玩法持有容量，`1～100`；普通每日总额度与之相同。           |
| `modes.<mode>.steal_probability`                                        | `0.3`                        | 抢夺成功概率；范围 `0～1`，页面按百分比展示。                |
| `modes.<mode>.steal_attempt_limit` / `stolen_limit`                     | `3` / `1`                    | 每周期尝试次数和目标被成功抢走次数；`0` 表示不限。           |
| `modes.<mode>.gift_mode`                                                | `direct`                     | `direct` 直接赠送，`confirm` 创建待确认邀请。                |
| `modes.wife.pool_ids` / `modes.husband.pool_ids`                        | `wuwa_wife` / `wuwa_husband` | 各角色玩法使用的角色池；空列表表示无候选角色池。             |
| `statistics.activity_window_days`                                       | `7`                          | 活跃度排行的天数窗口，`1～365` 天。                          |
| `display.pagination_enabled` / `display.page_size`                      | `true` / `10`                | 列表与排行分页；关闭分页时返回全部并按需分图。               |
| `history.retention_days`                                                | `30`                         | 全局历史数据保留天数，`1～3650`。                            |
| `messages.results.*` / `messages.errors.*` / `messages.notifications.*` | 见默认配置                   | 分别设置操作结果、错误提示和赠送通知；每条 1～500 字。       |

`<mode>` 分别是 `wife`、`husband`、`member`。每种玩法还可独立设置启用状态、抢夺与赠送开关、抢夺冷却、赠送邀请超时和解除关系次数。权重、统计分值、消息触发方式、名单、图片与导入限制也都在对应主题分区中。

列表和排行图片使用随插件附带的 Noto Sans SC 字体渲染；字体许可见 [resources/fonts/OFL.txt](./resources/fonts/OFL.txt)。亲密度与活跃度排行显示 QQ 昵称、QQ 号与头像；头像获取失败时显示 QQ 号末两位占位。带图回复将文字和图片放在同一条消息中。

## 管理页

在 AstrBot Dashboard 的插件页面打开「今日姻缘」管理页。任何已登录的 Dashboard 用户都可进入。页面提供：

- 运行概况、群作用域、逐条消息文案与全局或群级配置的预检和保存。
- 角色、角色池和图片管理；已保存与刚上传的图片都有缩略图，点击可查看大图。删除角色或池前会显示影响。
- 关系、配额、邀请、亲密度、活跃度及操作记录查询；管理员纠错需先预检再提交。
- JSON/ZIP 角色包预检与导入、角色包导出、完整备份及恢复预检。恢复会覆盖当前插件数据，提交前自动建立当前数据备份。

管理页的图片读取、上传和数据接口均要求 Dashboard 登录。

## 数据与安全

玩法配置、关系、群成员缓存、QQ 号、消息计数、亲密度、邀请和操作记录保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_daily_bonds/`。主要文件是 `state.sqlite3`；`media/` 保存角色素材，`avatars/` 保存 QQ 头像缓存，`backups/` 保存管理员生成的完整备份。源码目录不保存运行数据库。全局历史保留和头像缓存期限可配置。

内置角色图片在后台从清单中的外部地址下载并验证；群友头像会向 QQ 头像服务请求。网络或图片解码失败时，相关输出可退回文字。导入远程图片和 ZIP 包受来源、大小、条目、路径、解码与摘要检查。角色包导出只包含目录与素材；完整备份包含数据库及插件素材，请按包含群和用户数据的文件妥善保管。恢复前可预检作用域映射；重启或恢复后，未完成的确认赠送会被标为失效或结果未知。
