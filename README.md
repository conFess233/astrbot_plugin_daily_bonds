适用于接入 AstrBot 的 QQ 群：每天抽取今日老婆、今日老公或娶一位群友，可以抢夺、赠送、离婚，查看自己的姻缘状态和图鉴。管理员在管理页调整玩法、文案、群级规则和角色池。

## 核心亮点

| 能力           | 说明                                                                                   |
| -------------- | -------------------------------------------------------------------------------------- |
| 三种每日玩法   | 今日老婆、今日老公、娶群友，支持指定、抢夺、赠送和离婚。                               |
| 卡片回复       | 抽取结果、列表、排行、个人状态等渲染为卡片；可在管理页改为纯文本，也可按类型单独设置。 |
| 我的姻缘与图鉴 | 一条指令查看三种玩法的关系、剩余次数和冷却；图鉴按角色池显示收集进度。                 |
| 群友统计       | 亲密度、活跃度排行和双方亲密度查询，影响娶群友的抽取权重。                             |
| 角色管理       | 内置《鸣潮》《战双帕弥什》角色池，支持批量导入图片和仓库配置同步。                     |
| 群级配置       | 按群调整玩法、文案、回复形式和引用，未覆盖的字段继承全局配置。                         |
| AI 功能（可选） | 互动结果由模型现写文案；按聊天内容判断谁在对谁说话并加减亲密度。默认关闭。             |

<a id="quick-start"></a>

## 快速开始

运行要求：**AstrBot >= 4.29.0**，使用 **aiocqhttp** 适配器接入 QQ 群。娶群友需要 OneBot 端能获取群成员名单；卡片回复需要 AstrBot 的文转图（t2i）服务可用。

1. 在 AstrBot Dashboard 插件市场安装，或通过仓库地址 `https://github.com/conFess233/astrbot_plugin_daily_bonds` 安装。
2. 确认插件加载成功，插件配置中的 `enabled` 保持开启。
3. 在 QQ 群发送 `姻缘帮助`，收到本群可用指令的说明即表示插件正常工作。
4. 发送 `今日老婆`。首次启动会在后台下载内置角色图片；图片不可用时只回复文字。

默认只启用《鸣潮》老婆池和老公池。要使用《战双帕弥什》角色，在管理页「配置 → 玩法 → 角色池与候选」中启用对应角色池。

<details>
<summary>手动安装</summary>

在 AstrBot 安装目录执行，依赖必须安装到 **AstrBot 实际使用的 Python 环境**：

```bash
cd data/plugins
git clone https://github.com/conFess233/astrbot_plugin_daily_bonds.git
cd astrbot_plugin_daily_bonds
python -m pip install -r requirements.txt
```

安装后在 Dashboard 插件页重载插件；加载失败时查看日志并从失败列表重新加载。Docker 部署需在容器内安装依赖。

## 使用方法

以下为默认关键词，可在管理页修改。`<参数>` 表示必填，`[参数]` 表示可选，输入时不带括号。

### 抽取与关系

| 指令                                                                       | 作用                                                                                                 |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `今日老婆` / `今日老公` / `娶群友`                                         | 从启用的角色池或当前群友中随机抽取。                                                                 |
| `今日老婆 <名称或#ID>` / `今日老公 <名称或#ID>`                            | 指定角色，消耗每周期的指定次数。                                                                     |
| `抢老婆 @持有者 [名称或#ID]` / `抢老公 …` / `抢群友 @持有者 [QQ号或@对象]` | 按成功率抢夺对方的一段关系，省略对象时随机选择一段能抢的。                                           |
| `强娶 @群友`                                                               | 按成功率直接娶一位还没被任何人娶走的群友，默认每周期 1 次，失败也消耗。已被人娶走的群友用 `抢群友`。 |
| `送老婆 @接收者 [名称或#ID]` / `送老公 …` / `送群友 @接收者 [QQ号或@对象]` | 把自己的关系送给他人。只有一段可赠送的关系时可省略对象，有多段时列出候选，需写明送哪一段。           |
| `离婚 [名称、#ID、QQ号或@成员]`                                            | 解除自己的一段关系，只有一段时可省略目标；成功后可以再次抽取。                                       |
| `离婚老婆` / `离婚老公` / `踹群友`（`离婚群友`）                           | 限定玩法解除关系。踹群友不会把对方移出群。                                                           |
| `接受赠送 [编号]` / `拒绝赠送 [编号]` / `取消赠送 [编号]`                  | 赠送设为需要确认时使用；有多条待处理邀请时需填编号。                                                 |

### 查询

| 指令                                                      | 作用                                                                                                                                                                              |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `我的姻缘`                                                | 查看三种玩法的当前关系（来源、是否受保护、连续天数）、剩余次数、抢夺冷却和待处理赠送。                                                                                            |
| `我的图鉴 [老婆或老公]`                                   | 查看曾经拥有过的角色和次数，以及各角色池的收集进度。                                                                                                                              |
| `角色信息 <名称或#ID>`                                    | 查看本群角色池内某个角色的图片、别名、所属角色池、当前持有人、本群累计结缘次数和收集人数。                                                                                        |
| `本群统计`                                                | 查看统计窗口内的抽取、抢夺、强娶次数，以及最受欢迎的角色、抽取最多的人和亲密度最高的组合。                                                                                        |
| `姻缘帮助`                                                | 按本群生效的关键词和开关列出可用指令。                                                                                                                                            |
| `老婆列表 [页码]` / `老公列表 [页码]` / `群友列表 [页码]` | 查看本群当前关系，标注抽取、指定、赠送或抢夺来源。                                                                                                                                |
| `亲密度排行`                                              | 全群亲密度：同一对群友的双向记录合并为一行，按双向总分展示前 50 对，触发者所在的组合高亮。                                                                                        |
| `我的亲密度排行 [页码]`                                   | 你对群友的亲密度，从高到低分页列出。                                                                                                                                              |
| `活跃度排行 [页码]`                                       | 统计窗口内的消息数和活跃天数。                                                                                                                                                    |
| `查询好感度 @用户`                                        | 查询你与对方两个方向的累计亲密度。                                                                                                                                                |
| `/设置老婆 <角色名、别名或#ID>`                           | 仅 Bot 管理员或配置的额外管理员可用，直接为自己设置今日老婆，匹配规则与指定角色相同。不消耗次数、可超过持有上限；这段关系不受保护，可以被抢、赠送和离婚，来源显示「管理员设置」。 |

失败时回复会说明原因和下一步，例如次数用完时提示重置时间，持有已满时提示先离婚。格式错误、额度不足和受保护等失败不会开启通用冷却。

### 指令写法

- **触发方式**：指令可以直接发送，也可以加 AstrBot 命令前缀或在开头 @ 机器人。
- **@ 用户**：需要在 QQ 中选择成员，手动输入 `@名字` 无效。
- **开头 @ 其他群员**：这类聊天（如 `@群友 今日老婆`）不会触发指令；抢夺、赠送和查询好感度除外，`@乙 抢老婆` 等同于 `抢老婆 @乙`。
- **匹配对象**：抢夺、赠送、离婚里的对象和指定角色用同一套匹配。名称和别名不区分大小写，没有完全一致的名称时按包含匹配，多个结果会列出供选择。
- **ID 与群友**：ID 可省略来源前缀（`#1102` 即 `#wuwa:1102`）；群友可用当前名片、昵称或 QQ 号。

## 玩法规则

### 基础规则

- **周期**：按配置的时区和时间每日重置，默认北京时间 `00:00`。关系、次数和冷却都在周期结束时清空。
- **持有上限**：每种玩法一个上限（默认 1），抽取、指定、抢夺和赠送得到的关系共用。持有已满时不能再抽、指定、抢夺或接收赠送。
- **普通抽取**：每周期次数等于持有上限。离婚、被抢或对象退群后返还一次，可以再次抽取；送出关系不返还。
- **保护**：抢来的和指定得到的关系本周期受保护，不能被抢、送出或主动离婚，周期结束自然解除。赠送得到的关系和 `/设置老婆` 设置的关系不受保护。
- **重复对象**：已持有某个对象时不能再抢夺或接收相同的对象。

### 各玩法规则

- **指定**：默认每周期 1 次，`0` 表示关闭。默认要求角色独占，关闭后允许多人共享同一角色。
- **抢夺**：默认成功率 30%，每周期 3 次，冷却 60 秒，每人每周期最多被抢走 1 次。可开启亲密度加成。
- **强娶**：只有娶群友玩法有。默认基础成功率 20%，亲密度越高越容易成功。不占普通抽取次数，要有空余持有名额；得到的关系本周期受保护，来源显示「强娶」。对方已被任何人持有时不能强娶，也不扣次数。
- **娶群友**：候选人须是当前在群、未被占用、且在活跃度窗口内活跃过或与群友有亲密度记录的成员；关闭活跃度统计后不再要求候选人近期活跃。你对对方的亲密度越高、对方越活跃，越容易抽中。
- **双向奔赴**：你娶到的群友也娶了你时，会收到专属回复；抢夺或赠送促成时也会提示，`我的姻缘` 和群友列表会标记。

### 亲密度与连续天数

- **亲密度**：来自群聊里的 @、回复和戳一戳；同一条消息里既 @ 又回复同一人时只按 @ 计。指令里的 @ 和回复是操作目标，只计活跃度，不加亲密度。
- **AI 好感度评估**（默认关闭）：见下方 [AI 功能](#ai)。
- **亲密度衰减**（默认关闭）：开启后每天按比例扣减一段时间内没有新互动的亲密度，影响排行、抢夺加成和娶群友权重。
- **连续天数**：连续多天与同一对象结缘时，卡片和 `我的姻缘` 会显示连续天数。中间隔了没有人发言的日子不算连续，最长等于历史保留天数（默认 30 天）。

<details>
<summary>成功率、权重与衰减的计算</summary>

**抢夺成功率**（开启亲密度加成时，可设置加成后的上限）：

```text
成功率 = 基础成功率 + 你对持有者的亲密度 × 加成系数
```

**强娶成功率**（默认每点亲密度加 0.1%，加成后最高 80%）：

```text
成功率 = 基础成功率 + 你对对方的亲密度 × 加成
```

**娶群友权重**：

```text
权重 = min(最大权重, 基础权重 + 你对对方的亲密度 × 每点亲密度增加权重) × 活跃系数
活跃系数 = 零活跃天数系数 + (1 − 零活跃天数系数) × 对方在窗口内的活跃天数 ÷ 窗口天数
```

- 亲密度只看你对对方这一方向。
- 活跃天数按自然日计，发言或主动戳一戳都算，窗口内每天都活跃时系数为 1。
- 默认值下，亲密度 400 及以上达到最大权重 5，从未活跃的成员权重乘以 0.2。

**亲密度衰减**：扣减时向下取整，每次至少减 1 分，减到 0 的记录删除。插件停机多日后，下次清理时按经过的天数一次补齐。

**连续天数**：从保留的历史记录计算。

</details>

## AI 功能

两项功能都调用 AstrBot 中已配置的对话模型，默认关闭，在管理页「配置 → 高级 → AI 功能」设置。请求独立于主聊天：不带工具、不写入聊天历史，也不触发其他插件的 LLM 钩子。

**模型来源**：默认跟随该群当前使用的聊天模型和配置文件的默认人格；也可以指定多个模型，按勾选顺序依次尝试，前一个失败或超时再用下一个。人格只作为文风参考，“跟随会话”不包含对话中临时切换的人格。

### AI 互动文案

在「消息与关键词」中，下列回复多一个「使用 AI 生成」开关：抽到老婆 / 老公 / 群友、群友双向奔赴、指定老婆 / 老公、强娶成功 / 失败、抢夺成功 / 失败、赠送成功、赠送已接受、解除关系、抢夺或赠送促成双向奔赴。错误提示和通知始终使用预设文案。

- 业务先完成，再请模型根据本次的人物、对象和结果写一条；群友玩法会附上双方现有的亲密度（注明这次互动没有改变它）。不读取群聊内容。
- 每条回复可以单独填写「AI 提示词」，描述这一类回复的语气和侧重点；全局的文风要求和字数上限（默认 80 字）在「AI 文案」里设置。
- 预设文案默认不发给模型，避免照搬其中的数字和情节；需要时可打开「把预设文案作为示例发给模型」。
- 插件固定要求模型只写真实结果：生成内容出现事实里没有的数字，或声称亲密度、好感度涨跌时，视为不合格并改发预设文案。
- 「系统提示词」可整段改写，留空使用内置版本（编辑框的灰色占位文字即内置内容，可一键填入后再改）。只能使用变量 `{max_chars}`。无论怎么改，输出都会去掉 @、链接和 QQ 号，超过字数上限视为失败。
- 超时（默认整条回复最多等 8 秒，单个模型 5 秒）、出错、输出不合格或达到频率上限时，改发预设文案；业务结果不受影响。
- 角色图片仍按预设的 `{image}` 位置附上；卡片模式下生成的文案显示在卡片正文。
- 编辑器里的「试生成一条」用草稿和示例人物实际调用一次模型，结果只显示在页面上。

### AI 好感度评估

开启后，插件把本群的普通聊天（不含指令）暂存在内存里，每 30 分钟或积累 20 条时交给模型评估一次。评估有单独的超时（默认每个模型 45 秒），不受 AI 文案超时影响，也不占用文案的并发名额；本群调用额度用完时顺延到下一轮。

1. **判断说话对象**：@ 和回复直接认定；消息里出现群名片或昵称（点名），或两人之间你来我往的接话，作为提示交给模型；最后由模型确认。@ 和回复认定的对象模型不能改。
2. **评估态度**：模型按“一段对话”给出 -3～+3 的态度分。夸奖、关心为正，普通交流为 0，辱骂、恶意嘲讽为负。
3. **计分**：

```text
加减分 = (底分 + 态度分 × 态度分系数) × 模型对说话对象的把握
```

- 有 @ 或回复的对话已有固定分，只计态度分；模型识别出的隐式对话再加底分（默认 1）。把握低于 0.5 的隐式对话不计分。
- “嗯”“1”这类少于 2 个字的消息不参与态度评分。
- 默认可加可减，可改为只加不减；亲密度最低为 0。
- 每一对每天加分、扣分各自最多 10 分（`0` 表示不限）；当天累计变化超过 5 分后，之后的加减分减半。
- 模型输出逐项校验：代号不在名单里、分值越界或消息编号不对的项丢弃，其余照常计分；输出完全无法解析或全部不合格时换下一个模型，都失败则本批不计分。每批的结果（已计分、没有可计分的对话、作废）都记录在评估记录里。

「本群语境说明」可补充群里的说话习惯，例如“互称‘老婆’是玩笑”，减少误判；它插在判断规则和输出格式之间，不能改变两者。判断规则和输出格式本身不开放修改。

评估结果写入亲密度，影响排行、抢夺 / 强娶加成和娶群友权重；每批的加减记录可在「数据 → AI 好感度评估」查看，需要时用「管理员纠错」调整。

**注意**：对象判断和态度评估都会误判，尤其是多人同时聊天、反讽和圈内梗。它是让亲密度更贴近聊天的趣味机制，不是精确度量。

<a id="configuration"></a>

## 配置

业务配置只在插件管理页编辑，保存后在后续群事件中生效。AstrBot 原生插件配置页只保留启用开关 `enabled`，关闭后插件不启动。

管理页顶部选择「全局配置」或具体的群；在群范围内修改字段会建立该群的覆盖，取消覆盖即恢复继承全局。名单准入、资源限制、批量导入默认值和额外管理员只能全局配置。

### 常用选项

| 配置键                                                           | 默认值                               | 作用                                                                                             |
| ---------------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `enabled`                                                        | `true`                               | 业务总开关，可按群暂停。                                                                         |
| `modes.<玩法>.enabled`                                           | `true`                               | 启用老婆、老公或群友玩法。                                                                       |
| `modes.<玩法>.capacity`                                          | `1`                                  | 持有上限及每周期普通抽取次数，范围 `1～100`。                                                    |
| `modes.wife.pool_ids` / `modes.husband.pool_ids`                 | `["wuwa_wife"]` / `["wuwa_husband"]` | 启用的角色池；空列表表示没有可抽角色。                                                           |

### 回复文案

每条回复都可以单独设置，并支持按群覆盖：

- **文案**：点编辑框右上角的 `+` 可添加多条（最多 20 条），发送时随机选一条。标题和统计标签只有一条。
- **留空**：留空的条目不参与随机；全部留空时不发送这条回复，业务操作照常执行。
- **开关**：可以关闭发送，或设置为引用触发消息。

> 引用以插件开关为准：AstrBot 平台设置开启了「回复时引用」时，关闭引用的回复由插件直接发送，不会被补上引用，也不经过其他插件的发送前处理。

编辑器会列出文案可用的 `{变量}`：

- **常用变量**：`{actor_name}`（触发者）、`{name}`（抽到或查询的对象）、`{reset_at}`（下次重置时间）。
- **名称**：优先使用群名片，缺失时显示“群友”，不显示 QQ 号。
- **图片**：`{image}` 表示附图位置。卡片模式下替换为卡片，纯文本模式下附上原图；删除 `{image}` 即不附图。
- **大括号**：使用 `{{`、`}}` 输出。

## 管理页

在 AstrBot Dashboard 插件页面打开「今日姻缘」管理页。**所有已登录 Dashboard 的用户均可访问和操作**，不以 QQ 群管理员身份授权。

顶部导航分为五个模块。

### 概览

显示数据状态、当前周期、待处理事项、配置摘要和已记录的群。数据看板展示近 7/14/30 天的抽取趋势、抢夺和强娶成功率、热门角色和活跃的群，也可以查看数据表。

### 配置

- **玩法**：默认让三种玩法使用同一组数值，关闭后并排对照。抢夺、赠送、离婚、指定关闭时自动收起其次级设置，右侧按草稿显示「规则预览」。
- **消息与关键词**：按场景编辑文案（成功与失败相邻）并预览，另可编辑指令关键词。
- **高级**：分为基础与准入、指令、统计与权重、展示与回复形式、AI 功能、运行与存储六组。触发方式合为一项，回复形式可选全部卡片、全部文字或按类型，资源上限与缓存等默认折叠。

配置修改先进入草稿，右侧卡片列出每项改动的原值与新值，右下角按钮变为「放弃 / N 项未保存 / 保存」，保存成功后立即生效；版本冲突时保留草稿并显示差异。角色、图片、导入和维护操作各自提交，放弃配置草稿不会撤销它们。

### 角色

- **浏览与筛选**：角色以封面卡片展示，可以直接看到性别、图片数、缺图、停用和所属角色池。可按角色池、性别和状态（缺少图片、已停用）筛选，选中角色池时显示其角色数与缺图数。
- **批量操作**：点「批量操作」可多选角色（跨页保留），一次启用、停用或加入、移出角色池。
- **编辑角色**：拖入、粘贴或点击添加图片，已有角色的图片增删立即保存。图片多时右侧面板可加宽或全屏，点击缩略图用灯箱翻看。
- **其他**：批量导入角色图、仓库同步、角色池编辑和角色包导入。

<details>
<summary>批量导入角色图</summary>

1. 在「角色」模块点击 **批量导入角色图**，拖入图片或整个文件夹（也可点击选择、粘贴）。文件名或所在文件夹名写角色名即可，例如 `长离/01.png`、`【鸣潮】椿_立绘_03.webp`。单张最多 12 MiB，超过 6 MiB 的图片和 GIF、AVIF 等格式会先在浏览器里压缩或转为 WebP。

3. 标黄的分组需要处理：点 **可能是** 里的候选或 **更改角色** 搜索已有角色；没有对应角色时 **确认新建** 并选择角色池；不需要的图片点 **排除**。点缩略图可多选，只改选中的几张。
4. 点击 **导入 N 张**，已有角色追加图片，新角色按设置创建；需要处理的图片不会导入，可以之后继续。

未完成的批次保留 24 小时，仅创建者可见，下次打开时可选择 **继续该批次**。

## 数据与安全

运行数据位于 AstrBot 的 `data/plugin_data/astrbot_plugin_daily_bonds/`，不写入插件源码目录：

```text
astrbot_plugin_daily_bonds/
├── state.sqlite3       # 配置、关系、群成员缓存、统计、图鉴、邀请和操作记录
├── media/              # 角色图片
├── avatars/            # QQ 头像缓存
├── cache/              # 帮助卡片等固定内容的渲染缓存
├── staging/            # 导入、恢复和迁移的暂存文件
└── backups/            # 完整备份、升级前与导入前的数据库备份
```

保存的内容包括群成员名称与 QQ 号、消息计数、亲密度、活跃日期和管理操作记录，按群和机器人隔离。

外部请求：

- **卡片渲染**：卡片模式下，群名片、角色名和缩小后的头像、角色图会发送到 AstrBot 配置的 t2i 服务（默认使用 AstrBot 官方服务，可在 AstrBot 中改为自建服务）。将 `render.mode` 设为 `text` 后不再发送。
- **AI 互动文案**（开启后）：发起者、对象等名称、本次结果和双方亲密度发送给所选模型的提供方。
- **AI 好感度评估**（开启后）：本群普通聊天的原文（每条最多 200 字，图片等替换为占位文字）和成员的群名片、昵称发送给所选模型的提供方；QQ 号只以 P1、P2 代号出现。可关闭「发送群名片和昵称」只发代号。聊天原文只在内存中暂存，每群最多 200 条、所有群合计最多 5000 条，评估后、关闭评估、该群长时间无消息或插件重载时丢弃，不写入数据库或磁盘。
- 内置角色图片从角色清单中的地址下载；头像向 QQ 头像服务请求；仓库同步访问 GitHub。远程图片和导入文件会校验来源、大小、路径和格式。

完整备份包含数据库和群成员数据，请按包含个人数据的文件保管。

<details>
<summary>数据库可靠性</summary>

数据库使用 WAL 模式并设置 `synchronous=NORMAL`：插件或 AstrBot 进程崩溃不会丢失已完成的操作；服务器突然断电或系统崩溃时，最后几秒内的统计或操作可能丢失，但数据库不会损坏。

</details>

## 已知限制与常见问题

| 现象 / 条件                          | 行为与处理                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| 使用其他适配器或 AstrBot 低于 4.29.0 | 仅支持 aiocqhttp，请使用符合运行要求的环境。                                                     |
| 指令没有回复                         | 检查插件是否加载、两个启用开关、群与用户准入，以及关键词和前缀设置。                             |
| 卡片变成纯文字                       | t2i 服务不可用或超时时自动改发文字；检查 AstrBot 的文转图设置，或改为纯文本模式。                |
| 卡片底部留白较多                     | 卡片按 t2i 服务的页面截图生成，内容较少时下方保留背景。                                          |
| 群成员列表拉取失败                   | 沿用 1 小时内成功拉取的名单并稍后重试；超过 1 小时仍失败时该群暂停指令和统计，检查 OneBot 连接。 |
| 提示没有可抽取对象                   | 检查角色池是否启用、角色是否有图片；娶群友还需要成员名单和近期活跃记录。                         |
| 长排行使用合并转发                   | 依赖 OneBot 端支持合并消息；可开启分页或减少每页条数。                                           |
| 发送图片超过 1600 像素               | 按比例缩小临时副本发送，图库原图不变。                                                           |
| 配置保存提示冲突                     | 草稿保留；核对最新配置后重新提交。                                                               |
| 回复没有计入亲密度                   | 需要 AstrBot 取回被回复的原消息；消息太旧、已撤回或协议端不支持时不计回复分，@ 照常计分。        |
| AI 文案总是预设内容                  | 检查模型是否可用、是否超时或达到每群频率上限；可用「试生成一条」排查。                           |
| AI 好感度评估没有变化                | 评估每 30 分钟或积累 20 条才进行一次；只评估开启后收到的普通聊天，重载会丢弃尚未评估的消息。在「数据 → AI 好感度评估」查看每批结果。 |
| 平台适配器改过名字                   | 作用域按机器人 QQ 号和群号识别，改名后沿用原有数据；0.3.1 之前因改名分开的数据在升级时自动合并。 |
