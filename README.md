整合每日老婆/老公功能，并支持娶群友。内置《鸣潮》和《战双帕弥什》角色与角色池，也支持管理员添加角色、图片和角色池。内置角色按 ID 分别保存在 `resources/characters/`，角色池保存在 `resources/pools/`；战双角色池默认不加入抽取配置，可在管理页启用。

<a id="quick-start"></a>

## 快速开始

运行要求：AstrBot >= `4.28.2` ，仅支持aiocqhttp平台。

1. 克隆仓库或从插件市场安装。
2. 在 **AstrBot 所用的 Python 环境**中进入该插件目录，安装依赖并重启 AstrBot：

    ```bash
    python -m pip install -r requirements.txt
    ```

3. 在 AstrBot 插件配置中保持宿主开关 `enabled=true`。进入本插件管理页后确认领域开关 `enabled=true`、群允许参与，并等待内置角色图片下载完成。首次运行会建立数据库、内置角色和角色池；图片下载失败时可能只返回文字。
4. 在已接入的 QQ 群发送 `娶群友` 验证消息链路；发送 `今日老婆` 或 `今日老公` 验证角色池。成功时返回对象名称，能取得图片时一并发送图片。群成员名单需要 OneBot 端支持获取。

内置目录中的部分角色因原始素材不适合独立立绘而默认禁用。管理员可在管理页查看和补充图片。

## 群内指令

下表是默认关键词，可在管理页逐项修改。`<…>` 为必填，`[…]` 为可选，输入时不带括号。`@用户` 必须是 QQ 的真实 At 消息段，直接打出 `@名字` 文本不算。

| 指令                                                                  | 作用                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `今日老婆` / `今日老公` / `娶群友`                                    | 从相应角色池或当前合格群成员中抽取。                                  |
| `/设置老婆 <角色名/别名>` | 仅 Bot 管理员或全局额外命令管理员可用，给发送者设置今日老婆。 |
| `今日老婆 <名称或ID>` / `今日老公 <名称或ID>`                          | 指定当前角色池中的角色，使用独立指定次数和槽位。                      |
| `抢老婆 @持有者 [名称或#ID]` / `抢老公 @持有者 [名称或#ID]`           | 抢指定持有者的关系；省略对象时随机选择。也可将 `@持有者` 放在指令前。 |
| `抢群友 @持有者 [QQ号]`                                               | 抢该持有者的群友关系；可省略配偶 QQ 号。                              |
| `送老婆 @接收者 [名称或#ID]` / `送老公 @接收者 [名称或#ID]`           | 将自己持有的关系赠送给群成员。                                        |
| `送群友 @接收者 [QQ号]`                                               | 赠送自己的群友关系。                                                  |
| `离婚 [名称、#ID、QQ号或@成员]`                                       | 解除自己的老婆、老公或群友关系；只有一段关系时可省略目标。            |
| `离婚老婆 [名称或#ID]` / `离婚老公 [名称或#ID]`                       | 只查对应玩法；多段关系时需指定目标。                                  |
| `离婚群友 [@成员、QQ号或完整名称]` / `踹群友 [@成员、QQ号或完整名称]` | 解除自己的群友关系，不会将对方踢出群；支持结婚时及当前成员名称。      |
| `老婆列表 [页码]` / `老公列表 [页码]` / `群友列表 [页码]`             | 分别查看本群各玩法当前关系，抢夺槽位关系会标记“抢夺”。                |
| `亲密度排行 [页码]` / `活跃度排行 [页码]`                             | 查看本群排行；排行方式和统计窗口由配置决定。                          |
| `查询好感度 @用户`                                                    | 查看自己与目标群友两个方向的累计好感度。                              |
| `接受赠送 [邀请编号]` / `拒绝赠送 [邀请编号]` / `取消赠送 [邀请编号]` | 处理需确认的赠送；同时有多条待处理邀请时必须填写编号。                |

角色 `#ID` 是角色的固定 ID，不进行模糊搜索。离婚指令只匹配自己在本群当前周期的关系；跨玩法或同名匹配时列出候选，需改用明确玩法及目标。一次普通抽取的每日总额度默认等于该玩法的持有容量；成功解除关系会获得一次补抽资格。抢夺有独立的概率、次数和冷却；有效抢夺尝试即使失败也会计入次数。赠送默认直接完成，可改成接收者确认模式。周期按配置的时区和重置时间计算。

三种玩法各有独立的抢夺槽位，默认各 1 个。抢夺成功后进入对应槽位，不占普通持有容量；槽位满时立即提示，且不消耗抢夺次数或抢夺冷却。槽位中的关系在本周期不能主动离婚、赠送或再次被抢；无目标离婚只在普通关系中选择。群友离群、黑名单和参与资格变化仍按现有规则自动结束关系。管理员可纠错，周期结束也会结束关系。将某玩法的槽位数设为 `0` 可使用旧的普通容量抢夺规则。

`/设置老婆` 匹配当前启用的老婆角色池中的精确角色名或别名，允许开头先 @ 机器人。成功不消耗普通或指定抽取次数、补抽资格，也不受普通容量限制；不同用户可持有同一角色，同一用户不能通过此命令重复持有。它创建普通老婆关系，指定槽位的保护和额度规则仍独立生效。

指定抽取支持精确角色名称、别名、原始 ID 和 `#ID`，ID 优先；同名或别名冲突会列出候选，需使用明确 ID。角色必须属于当前群该玩法选用的池、启用且已有登记图片。老婆和老公的指定额度分别配置，每周期默认各 1 次，同时也是指定槽位上限，设为 `0` 禁用。成功才扣次数，不占普通抽取与抢夺槽位；指定关系不能被抢、赠送或主动离婚。管理员纠错、重置和参与资格变化仍可结束关系，但不退指定次数。

“指定角色只能拥有一段关系”默认开启，指定已被持有的角色会被拒绝。关闭时可多人共享，同一人也可重复指定，每次分别扣次数、占槽位；普通随机抽取仍排除已被持有的角色。重新开启只限制新指定，不清理已有共享关系。

今日老婆或今日老公达到普通持有上限后，上限为 1 时分别使用“已有老婆”或“已有老公”模板，可加入 `{name}` 与 `{image}`；未配置图片占位符时只发送文字。多段普通关系的提示可使用 `{names}`，添加 `{image}` 时显示已有关系图片。

管理页“数据查询”中可按群和玩法点击“重置关系”或“重置每日数据”，在弹窗核对影响后执行，无需填写操作理由。两者仅作用于当前周期：前者结束活跃关系，但不恢复每日额度或发放补抽；后者清零每日抽取、偷取和离婚计数，但不结束关系。历史、亲密度、活跃度、补抽资格及待处理赠送均保留。关系重置后，绑定原关系的待处理赠送会在接收时提示失效。

默认支持裸关键词、宿主当前命令前缀和开头 At 机器人。未识别的聊天不会收到插件回复。通用指令冷却默认 3 秒；格式错误、保护拒绝和额度不足不会开启新冷却，接受、拒绝和取消赠送不受通用冷却约束。

## 配置

AstrBot 原生插件配置页可编辑全部全局业务配置。顶层 `enabled` 是**宿主启动开关**：关闭后插件不打开数据库；`settings.enabled` 是**领域开关**：可暂停全局或单个群的玩法。两者都需启用。原生配置页与管理页的全局配置会同步；群级覆盖仍在管理页编辑。已有管理页配置在升级时保留。

管理页按主题提供配置子标签，切换标签时保留未保存草稿。选择「全局」或一个群后修改字段，依次使用**校验草稿**和**保存配置**；**放弃草稿**撤销未保存编辑。群配置逐字段标明「继承全局」或「本群覆盖」，关闭覆盖即恢复继承。全局资源、历史保留、群访问规则和额外命令管理员名单只能全局配置。保存会校验完整生效配置和版本；冲突时保留草稿。新配置在后续群事件中生效，当前周期的重置安排按周期规则延续。

切换群作用域或保存期间，配置编辑与提交入口暂时禁用。切换失败会保留原作用域与配置；保存失败保留草稿。角色目录支持搜索与分页，搜索和刷新列表保留编辑中的角色池选择。

「群内操作结果」「群内错误提示」「赠送与重启通知」「标题与统计标签」分区可修改机器人文案。变量使用 `{name}`、`{invite_id}` 等形式；控件会列出后端允许的变量，预检拒绝未知变量、无效大括号和缺失的必要变量。输入 `{{`、`}}` 可显示字面大括号。模板允许仅填 `{image}`，但不能完全空白；每条最多 1000 字符。邀请编号等必要信息不能省略。

带图回复的 `{image}` 表示图片插入位置，例如 `你今日已有{name}啦，不要太贪心哦。{image}`。多图按顺序插入，重复占位符会在对应位置再次插入图片；删除占位符即可关闭图片。没有可用图片时保留文字，仅图片模板则使用对应文字结果兜底。旧版成功抽取模板升级时会自动追加 `{image}`，保留原来的附图行为。

「结果回复引用」「错误回复引用」可逐条设置是否引用触发消息，默认关闭，支持群级覆盖。合并消息的引用放在首个转发节点；定时通知没有触发消息时直接发送。已经排入发送队列的通知保留入队时的文本。

常用字段如下，完整字段、默认值与结构见 [resources/default-config.json](./resources/default-config.json)。管理页可编辑其中所有可写项，无需手写 JSON。

| 配置键                                                                  | 默认值                       | 作用                                                         |
| ----------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| `enabled`                                                               | `true`                       | 领域总开关；群级可单独暂停。                                 |
| `access.groups.mode` / `access.users.mode`                              | `unrestricted`               | `unrestricted`、`blacklist`、`whitelist`；空白名单拒绝全部。 |
| `access.extra_admin_ids` | `[]` | 额外可使用 `/设置老婆` 的 QQ 号，只能全局配置。 |
| `access.extra_bot_ids`                                                  | `[]`                         | 补充无法自动识别的机器人 QQ 号，避免进入候选或统计。         |
| `reset.timezone` / `reset.time`                                         | `Asia/Shanghai` / `00:00`    | 每日周期所用 IANA 时区和 `HH:mm` 时间。                      |
| `commands.cooldown_seconds`                                             | `3`                          | 通用指令冷却，`0` 关闭，最大 `86400` 秒。                    |
| `modes.<mode>.capacity`                                                 | `1`                          | 各玩法持有容量，`1～100`；普通每日总额度与之相同。           |
| `modes.<mode>.steal_slot_capacity`                                      | `1`                          | 独立抢夺槽位数，`0～100`；`0` 时沿用普通容量规则。           |
| `modes.wife.designated_capacity` / `modes.husband.designated_capacity`    | `1` / `1`                    | 每周期指定次数与槽位共用上限，`0～100`；`0` 关闭指定。       |
| `modes.wife.designated_unique` / `modes.husband.designated_unique`        | `true` / `true`              | 指定抽取遵守角色独占；关闭允许共享和重复指定。              |
| `modes.<mode>.steal_probability`                                        | `0.3`                        | 抢夺成功概率；范围 `0～1`，页面按百分比展示。                |
| `modes.<mode>.steal_attempt_limit` / `stolen_limit`                     | `3` / `1`                    | 每周期尝试次数和目标被成功抢走次数；`0` 表示不限。           |
| `modes.<mode>.gift_mode`                                                | `direct`                     | `direct` 直接赠送，`confirm` 创建待确认邀请。                |
| `modes.wife.pool_ids` / `modes.husband.pool_ids`                        | `wuwa_wife` / `wuwa_husband` | 各角色玩法使用的角色池；空列表表示无候选角色池。             |
| `statistics.activity_window_days`                                       | `7`                          | 活跃度排行的天数窗口，`1～365` 天。                          |
| `display.pagination_enabled` / `display.page_size`                      | `true` / `10`                | 列表与排行分页；关闭分页时返回全部并按需分图。               |
| `display.rank_merge_rows` / `display.rank_max_height`                   | `20` / `2000`                | 当前页排行超过条数或图高（像素）时分段，使用合并转发。      |
| `history.retention_days`                                                | `30`                         | 全局历史数据保留天数，`1～3650`。                            |
| `messages.*.*`                                                        | 见默认配置                   | 操作结果、错误、通知、图片标题与统计标签；每条 1～1000 字。 |
| `reply_quote.results.*` / `reply_quote.errors.*`                       | `false`                      | 对应回复是否引用触发消息；可按群覆盖。                     |

`<mode>` 分别是 `wife`、`husband`、`member`。每种玩法还可独立设置启用状态、抢夺与赠送开关、抢夺冷却、赠送邀请超时和解除关系次数。“老婆列表”和“老公列表”有独立关键词，原有自定义的“老婆列表”关键词继续只对应老婆。权重、统计分值、消息触发方式、名单、图片与导入限制也都在对应主题分区中。

列表和排行图片使用随插件附带的 Noto Sans SC 字体渲染；字体许可见 [resources/fonts/OFL.txt](./resources/fonts/OFL.txt)。亲密度、活跃度及好感度卡片显示群名片（缺失时用昵称）和头像，不附加 QQ 号；头像失败时显示 `?` 占位。个人亲密度排行标题显示发送者头像与“发送者群昵称与群友的亲密度排行”，按发送者对群友的累计分数排序；全群有向排行仍可配置。

排行默认只发送图片，渲染失败降级文字；用户可在模板中添加文字或关闭图片。长排行按条数和图片高度分段，每张图片一个合并转发节点；失败时改为分段文字节点。分页开启时阈值作用于当前页。活跃度同时展示消息数与活跃天数，仍按消息数排序。窗口内发送合格消息或主动戳一戳都算活跃，同一自然日期仅计一次；被戳不算活跃，主动戳机器人只计活跃天数、不增加消息数或亲密度。

统计窗口沿用滚动 `N×24` 小时，活跃日期按群配置时区划分，因此窗口可能跨越 `N+1` 个自然日期。旧消息可回算活跃日期，旧戳缺少发起者记录，无法回补。`查询好感度` 必须真实 @ 一位当前合格的其他群友，展示“你→对方”和“对方→你”两个分数，缺失方向为 `0`；默认图片，失败降级文字。

发送横图或竖图时保留完整画面和比例；宽或高超过 1600 像素时缩小发送用的临时副本，图库原图不变。这同样应用于排行及合并消息中的图片。

群友列表的每段关系显示持有者与群友双方的 QQ 头像、昵称及 QQ 号；头像失败时显示占位图，文字仍保留双方 QQ 号。

<a id="webui"></a>

## 管理页

在 AstrBot Dashboard 的插件页面打开「今日姻缘」管理页。任何已登录的 Dashboard 用户都可进入。页面提供：

- 运行概况、群作用域、逐条消息文案与全局或群级配置的预检和保存。
- 角色、角色池和图片管理；图片可多选上传，每张独立校验，单张失败不影响其他图片；已保存与刚上传的图片都有缩略图，点击可查看大图。删除角色或池前会显示影响。在配置管理的“今日老婆”和“今日老公”标签中，可分别为全局或指定群切换每个角色池；群级关闭“本群覆盖”时继承全局选择。
- 打开管理页时检查仓库默认分支的完整角色与角色池目录；发现更新后可在角色目录查看差异并批量选择同步。新增和无本地改动的项目默认勾选，冲突默认跳过但可明确覆盖；仓库移除的内容保留在本地，图片只追加。所选项目在图片校验通过后整批提交，并记录同步基线。
- 仓库同步最多读取 1000 个角色与角色池配置文件；单个 JSON 响应、单个配置文件及配置文件总量上限均为 50 MiB（52,428,800 字节）。
- 关系、普通与抢夺槽位配额、邀请、亲密度、活跃度及操作记录查询；管理员纠错需先预检再提交。简短成功与错误提示显示在右上角。
- JSON/ZIP 角色包预检与导入、角色包导出、完整备份及恢复预检。恢复会覆盖当前插件数据，提交前自动建立当前数据备份。

恢复成功后会同步 AstrBot 全局配置。若提示“数据已恢复，但同步到 AstrBot 配置失败”，可重试本次提交完成同步，无需再次覆盖数据；重载也会优先采用恢复后的配置。

管理页的图片读取、上传和数据接口均要求 Dashboard 登录。

### 批量导入角色图

在「角色目录」点击 **批量导入角色图**，选择多张图片或拖入选择区。支持 PNG、JPEG、WebP，每张最多 12 MiB、4000 万像素；批次条目数和总上传字节数沿用资源配置的导入上限。上传仅保存暂存图片与草稿，不立即修改角色或正式素材库。

1. 选择默认男、女卡池，按需调整检测关键词。关键词默认 `男、male` 与 `女、female`；英文忽略大小写，`female` 不会重复算作 `male`。可保存为后台全局默认，也可仅应用到本批次。默认映射只决定新角色的归属池，不会自动启用该池的抽取配置。
2. 上传后逐项预览。先用完整去扩展名的文件名匹配角色 ID，再匹配名称或别名；未命中时尝试去除性别关键词和末尾图片序号，如 `角色名_女_01.png`、`角色ID_男_02.webp`。匹配范围为全部未软删除角色，包括停用角色。
3. 已匹配角色只追加图片，保留其名称、别名、性别、启用状态和卡池。可搜索已有角色并更换关联 ID，此操作不会重命名原角色。未匹配项可关联已有角色或新建；新角色名称取清理后的文件名，ID 自动生成且可修改，同名图片默认指向同一个新角色草稿。
4. 男女关键词冲突、名称歧义或未知性别进入待人工列表；未知性别草稿暂按男标注。已有角色优先使用原档案，不被文件名检测结果覆盖。检查可靠项后点击 **确认导入可靠项**，核对成功与失败列表，再确认进入人工处理页面。
5. 对待人工项调整目标、名称、ID、性别和卡池，保存修正并勾选审核确认，再点击 **确认导入已审核项**。更改角色字段会撤销原审核确认；字段尚未填完整的新角色草稿可保存，批准或提交时必须完整合法。

同角色图片按内容哈希去重，已有图与新增图合计最多 20 张；超限时该角色不会自动导入前 20 张，须人工选择要保留的图片或更换目标。各角色独立提交，失败不阻断其他角色；已成功项不会因为后续失败或关闭窗口而撤销。失败文件会保留原因，可跳过后重新选择原文件上传。

关闭窗口会保存修正草稿，未完成批次可在 **恢复未完成批次** 中重新打开，保留期为创建后 24 小时，且只对创建它的 Dashboard 用户可见。未保存编辑遇到刷新或离开页面会提醒。超期草稿与暂存文件不再可用，后台清理任务会移除过期暂存；已导入的角色与图片不受影响。

## 数据与安全

玩法配置、关系、群成员缓存、QQ 号、消息计数、亲密度、邀请和操作记录保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_daily_bonds/`。主要文件是 `state.sqlite3`；`media/` 保存角色素材，`avatars/` 保存 QQ 头像缓存，`backups/` 保存管理员生成的完整备份。源码目录不保存运行数据库。全局历史保留和头像缓存期限可配置。

内置角色图片在后台从清单中的外部地址下载并验证；群友头像会向 QQ 头像服务请求。网络或图片解码失败时，相关输出可退回文字。导入远程图片和 ZIP 包受来源、大小、条目、路径、解码与摘要检查。角色包导出只包含目录与素材；完整备份包含数据库及插件素材，请按包含群和用户数据的文件妥善保管。恢复前可预检作用域映射；重启或恢复后，未完成的确认赠送会被标为失效或结果未知。
