适用于接入 AstrBot 的 QQ 群：每天抽取今日老婆、今日老公或娶一位群友，可以抢夺、赠送、离婚，查看自己的姻缘状态和图鉴。管理员在管理页调整玩法、文案、群级规则和角色池。

## 核心亮点

| 能力 | 说明 |
| --- | --- |
| 三种每日玩法 | 今日老婆、今日老公、娶群友，支持指定、抢夺、赠送和离婚。 |
| 卡片回复 | 抽取结果、列表、排行、个人状态等渲染为卡片；可在管理页改为纯文本，也可按类型单独设置。 |
| 我的姻缘与图鉴 | 一条指令查看三种玩法的关系、剩余次数和冷却；图鉴按角色池显示收集进度。 |
| 群友统计 | 亲密度、活跃度排行和双方好感度，影响娶群友的抽取权重。 |
| 角色管理 | 内置《鸣潮》《战双帕弥什》角色池，支持批量导入图片和仓库配置同步。 |
| 群级配置 | 按群调整玩法、文案、回复形式和引用，未覆盖的字段继承全局配置。 |

<a id="quick-start"></a>

## 快速开始

运行要求：**AstrBot >= 4.29.0**（管理页使用插件可视化视图 `views/`），使用 **aiocqhttp** 适配器接入 QQ 群。娶群友需要 OneBot 端能获取群成员名单；卡片回复需要 AstrBot 的文转图（t2i）服务可用。

1. 在 AstrBot Dashboard 插件市场安装，或通过仓库地址 `https://github.com/conFess233/astrbot_plugin_daily_bonds` 安装。
2. 确认插件加载成功，插件配置中的 `enabled` 保持开启。
3. 在 QQ 群发送 `姻缘帮助`，收到本群可用指令的说明即表示插件正常工作。
4. 发送 `今日老婆`。首次启动会在后台下载内置角色图片；图片不可用时只回复文字。

默认只启用《鸣潮》老婆池和老公池。要使用《战双帕弥什》角色，在管理页「配置 → 玩法 → 角色池与候选」中启用对应角色池。

<details>
<summary>手动安装</summary>

在 AstrBot 安装目录执行，依赖必须安装到 **AstrBot 实际使用的 Python 环境**：

```bash
cd data/plugins
git clone https://github.com/conFess233/astrbot_plugin_daily_bonds.git
cd astrbot_plugin_daily_bonds
python -m pip install -r requirements.txt
```

安装后在 Dashboard 插件页重载插件；加载失败时查看日志并从失败列表重新加载。Docker 部署需在容器内安装依赖。

</details>

<a id="usage"></a>

## 使用方法

以下为默认关键词，可在管理页修改。`<参数>` 表示必填，`[参数]` 表示可选，输入时不带括号。`@用户` 需要在 QQ 中选择成员，手动输入 `@名字` 无效。

指令可以直接发送，也可以加 AstrBot 命令前缀或在开头 @ 机器人。开头 @ 其他群员的聊天（如 `@群友 今日老婆`）不会触发指令。

### 抽取与关系

| 指令 | 作用 |
| --- | --- |
| `今日老婆` / `今日老公` / `娶群友` | 从启用的角色池或当前群友中随机抽取。 |
| `今日老婆 <名称或#ID>` / `今日老公 <名称或#ID>` | 指定角色，消耗每周期的指定次数。 |
| `抢老婆 @持有者 [名称或#ID]` / `抢老公 …` / `抢群友 @持有者 [QQ号]` | 按成功率抢夺对方的一段关系，省略对象时随机选择。 |
| `送老婆 @接收者 [名称或#ID]` / `送老公 …` / `送群友 @接收者 [QQ号]` | 把自己的关系送给他人。 |
| `离婚 [名称、#ID、QQ号或@成员]` | 解除自己的一段关系，只有一段时可省略目标；成功后获得一次补抽资格。 |
| `离婚老婆` / `离婚老公` / `踹群友`（`离婚群友`） | 限定玩法解除关系。踹群友不会把对方移出群。 |
| `接受赠送 [编号]` / `拒绝赠送 [编号]` / `取消赠送 [编号]` | 赠送设为需要确认时使用；有多条待处理邀请时需填编号。 |

### 查询

| 指令 | 作用 |
| --- | --- |
| `我的姻缘` | 查看三种玩法的当前关系（来源、是否受保护、连续天数）、剩余次数、抢夺冷却和待处理赠送。 |
| `我的图鉴 [老婆或老公]` | 查看曾经拥有过的角色和次数，以及各角色池的收集进度。 |
| `姻缘帮助` | 按本群生效的关键词和开关列出可用指令。 |
| `老婆列表 [页码]` / `老公列表 [页码]` / `群友列表 [页码]` | 查看本群当前关系，标注抽取、指定、赠送或抢夺来源。 |
| `亲密度排行 [页码]` / `活跃度排行 [页码]` | 查看亲密度或统计窗口内的消息数和活跃天数。 |
| `查询好感度 @用户` | 查询你与对方两个方向的累计亲密度。 |
| `/设置老婆 <角色名或别名>` | 仅 Bot 管理员或配置的额外管理员可用，直接为自己设置今日老婆。 |

失败时回复会说明原因和下一步，例如次数用完时提示重置时间，持有已满时提示先离婚。格式错误、额度不足和受保护等失败不会开启通用冷却。

<a id="rules"></a>

## 玩法规则

- **周期**：按配置的时区和时间每日重置，默认北京时间 `00:00`。关系、次数和冷却都在周期结束时清空。
- **持有上限**：每种玩法一个上限（默认 1），抽取、指定、抢夺和赠送得到的关系共用。持有已满时不能再抽、指定、抢夺或接收赠送。
- **普通抽取**：每周期次数等于持有上限；离婚成功获得一次补抽资格。
- **保护**：抢来的和指定得到的关系当天受保护，不能被抢、送出或主动离婚，周期结束自然解除。
- **抢夺**：默认成功率 30%，每周期 3 次，冷却 60 秒，每人每周期最多被抢走 1 次。可开启亲密度加成：成功率 = 基础成功率 + 你对持有者的亲密度 × 加成系数，并设置加成后的上限。
- **指定**：默认每周期 1 次，`0` 表示关闭。默认要求角色独占，关闭后允许多人共享同一角色。
- **娶群友**：候选人须是当前在群、未被占用、且近期活跃或与群友有亲密度记录的成员。亲密度越高、活跃天数越多，被抽中的权重越高。你娶到的群友也娶了你时，会收到「双向奔赴」的专属回复。
- **连续天数**：连续多天与同一对象结缘时，卡片和 `我的姻缘` 会显示连续天数。连续天数从保留的历史记录计算，最长等于历史保留天数（默认 30 天）。

<a id="configuration"></a>

## 配置

业务配置只在插件管理页编辑，保存后在后续群事件中生效。AstrBot 原生插件配置页只保留启用开关 `enabled`，关闭后插件不启动。

管理页顶部选择「全局配置」或具体的群；在群范围内修改字段会建立该群的覆盖，取消覆盖即恢复继承全局。名单准入、资源限制、批量导入默认值和额外管理员只能全局配置。

### 常用选项

| 配置键 | 默认值 | 作用 |
| --- | --- | --- |
| `enabled` | `true` | 业务总开关，可按群暂停。 |
| `modes.<玩法>.enabled` | `true` | 启用老婆、老公或群友玩法。 |
| `modes.<玩法>.capacity` | `1` | 持有上限及每周期普通抽取次数，范围 `1～100`。 |
| `modes.wife.pool_ids` / `modes.husband.pool_ids` | `["wuwa_wife"]` / `["wuwa_husband"]` | 启用的角色池；空列表表示没有可抽角色。 |
| `modes.wife.designated_limit` / `modes.husband.designated_limit` | `1` | 每周期指定次数，范围 `0～100`，`0` 关闭指定。 |
| `modes.<玩法>.steal_probability` | `0.3` | 抢夺基础成功率，管理页按百分比显示。 |
| `modes.<玩法>.steal_intimacy_bonus` / `steal_probability_max` | `0` / `0.9` | 每点亲密度增加的成功率，以及加成后的上限；`0` 关闭加成。 |
| `modes.<玩法>.gift_mode` | `direct` | `direct` 直接赠送；`confirm` 需要接收者确认。 |
| `reset.timezone` / `reset.time` | `Asia/Shanghai` / `00:00` | 每日周期的时区和重置时间。 |
| `commands.cooldown_seconds` | `3` | 通用指令冷却，`0` 关闭。 |
| `render.mode` | `card` | 回复形式：`card` 卡片或 `text` 纯文本。 |
| `render.types.<类型>` | `inherit` | 按类型覆盖回复形式，类型为 `draw`、`status`、`help`、`list`、`rank`、`affection`、`collection`。 |
| `statistics.activity_window_days` | `7` | 活跃度统计窗口，范围 `1～365` 天。 |
| `display.page_size` / `display.rank_merge_rows` | `10` / `20` | 列表每页条数；每张卡片最多行数（排行最多 30 行）。 |
| `history.retention_days` | `30` | 历史保留天数，也决定连续天数的上限。 |

`<玩法>` 为 `wife`、`husband` 或 `member`。完整字段与默认值见 [默认配置](./resources/default-config.json)，管理页对每个字段给出范围说明。

### 回复文案

每条回复都可以修改文案、关闭发送或设置为引用触发消息，支持按群覆盖。文案留空时不发送这条回复，业务操作照常执行。

文案中的 `{变量}` 由编辑器列出，例如 `{actor_name}`（触发者）、`{name}`（抽到或查询的对象）、`{reset_at}`（下次重置时间）。名称优先使用群名片，缺失时显示“群友”，不显示 QQ 号。`{image}` 表示附图位置：卡片模式下替换为卡片，纯文本模式下附上原图；删除 `{image}` 即不附图。使用 `{{`、`}}` 输出大括号。

## 管理页

在 AstrBot Dashboard 插件页面打开「今日姻缘」管理页。**所有已登录 Dashboard 的用户均可访问和操作**，不以 QQ 群管理员身份授权。

顶部导航分为五个模块：

| 模块 | 操作 |
| --- | --- |
| 概览 | 数据状态、当前周期、待处理事项、配置摘要和已记录的群。 |
| 配置 | 分「玩法」「消息与关键词」「高级」三类。玩法页并排对照三种玩法参数，右侧按草稿显示「规则预览」；消息页按场景编辑文案（成功与失败相邻）并预览，另可编辑指令关键词；高级页包括总开关、准入名单、重置时间、统计权重、显示、回复形式、资源限制和历史保留。 |
| 角色 | 角色编辑、多图上传、批量导入角色图、仓库同步、角色池编辑、角色包导入。 |
| 数据 | 按群查询关系、配额、统计、邀请和操作历史；查询用户今日状态；对比「姻缘帮助」的卡片与纯文本；管理员纠错和周期重置。 |
| 备份与迁移 | 角色包导出、完整备份与恢复、版本迁移及迁移记录。 |

配置修改先进入草稿，右侧卡片列出每项改动的原值与新值，右下角按钮变为「放弃 / N 项未保存 / 保存」，保存前会显示影响范围；版本冲突时保留草稿并显示差异。角色、图片、导入和维护操作各自提交，放弃配置草稿不会撤销它们。

<details>
<summary>批量导入角色图</summary>

1. 在「角色」模块点击 **批量导入角色图**，选择图片或文件夹。支持 PNG、JPEG、WebP，单张最多 12 MiB；超过 6 MiB 的图片会在浏览器中先压缩。
2. 选择默认男女池和检测关键词，上传后检查匹配结果。文件名按 ID、名称、别名匹配已有角色，去除性别词和序号后再尝试。
3. 已有角色只追加图片；未匹配的图片可关联已有角色或新建角色。
4. 点击 **确认导入可靠项**，再处理需要人工审核的项目。按角色分别提交，单个角色失败不影响其他角色。

未完成的批次保留 24 小时，仅创建者可见，可通过 **恢复未完成批次** 继续。

</details>

## 从 0.1.x 升级

首次以 0.2.0 启动时，插件会：

1. 把数据库复制到 `backups/pre-migration-v13-<时间>.sqlite3`；
2. 转换全局和各群的配置：合并文案的启用与引用开关，`designated_capacity` 改名为 `designated_limit`，删除 `steal_slot_capacity`、字体和图片高度设置；
3. 如果你在 0.1.x 的 AstrBot 原生配置页修改过业务配置且尚未同步，导入这些修改后清空原生页中的旧配置；
4. 用历史关系回填图鉴（早于历史保留天数的记录已被清理，无法回填）。

每一步的结果记录在管理页「备份与迁移」的迁移记录中。原先使用的仍是 0.1.x 默认文案会更新为带重置时间和提示的新版文案，自定义文案保持不变。

**持有规则变化**：0.1.x 中抢夺和指定使用独立槽位，0.2.0 起与普通关系共用持有上限。升级当天已经超出新上限的关系保留到周期结束。

需要回退或导入旧数据时，在「版本迁移」中选择升级前备份或上传旧版 `state.sqlite3`，预检后确认。导入会先备份当前数据库，迁移失败时自动还原；角色图片不随数据库导入。完整备份 ZIP 仍通过「完整恢复」导入，恢复后同样自动迁移。

## 数据与安全

运行数据位于 AstrBot 的 `data/plugin_data/astrbot_plugin_daily_bonds/`，不写入插件源码目录：

```text
astrbot_plugin_daily_bonds/
├── state.sqlite3       # 配置、关系、群成员缓存、统计、图鉴、邀请和操作记录
├── media/              # 角色图片
├── avatars/            # QQ 头像缓存
├── staging/            # 导入、恢复和迁移的暂存文件
└── backups/            # 完整备份、升级前与导入前的数据库备份
```

保存的内容包括群成员名称与 QQ 号、消息计数、亲密度、活跃日期和管理操作记录，按群和机器人隔离。

外部请求：

- **卡片渲染**：卡片模式下，群名片、角色名和缩小后的头像、角色图会发送到 AstrBot 配置的 t2i 服务（默认使用 AstrBot 官方服务，可在 AstrBot 中改为自建服务）。将 `render.mode` 设为 `text` 后不再发送。
- 内置角色图片从角色清单中的地址下载；头像向 QQ 头像服务请求；仓库同步访问 GitHub。远程图片和导入文件会校验来源、大小、路径和格式。

完整备份包含数据库和群成员数据，请按包含个人数据的文件保管。

## 已知限制与常见问题

| 现象 / 条件 | 行为与处理 |
| --- | --- |
| 使用其他适配器或 AstrBot 低于 4.29.0 | 仅支持 aiocqhttp，请使用符合运行要求的环境。 |
| 指令没有回复 | 检查插件是否加载、两个启用开关、群与用户准入，以及关键词和前缀设置。 |
| 卡片变成纯文字 | t2i 服务不可用或超时时自动改发文字；检查 AstrBot 的文转图设置，或改为纯文本模式。 |
| 卡片底部留白较多 | 卡片按 t2i 服务的页面截图生成，内容较少时下方保留背景。 |
| 提示没有可抽取对象 | 检查角色池是否启用、角色是否有图片；娶群友还需要成员名单和近期活跃记录。 |
| 长排行使用合并转发 | 依赖 OneBot 端支持合并消息；可开启分页或减少每页条数。 |
| 发送图片超过 1600 像素 | 按比例缩小临时副本发送，图库原图不变。 |
| 配置保存提示冲突 | 草稿保留；核对最新配置后重新提交。 |
